# Backend Foundation

This directory is the Phase 1 contract for the production backend.

The current repository is a static prototype. Production implementation will migrate
to Next.js + TypeScript and move these responsibilities into server-side modules:

- auth
- workspaces
- products
- assets
- generations/jobs
- AI router
- credits
- campaigns
- billing
- publishing
- analytics
- admin

Do not place real credentials here.

- `../docs/MASTER_PRODUCT_SPEC.md`
- `../docs/PHASED_IMPLEMENTATION_ROADMAP.md`
- `../docs/AI_PROVIDER_CONTRACT.md`
